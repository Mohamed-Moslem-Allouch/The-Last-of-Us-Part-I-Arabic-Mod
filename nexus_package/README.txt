[ENGLISH]
Thank you for downloading the Arabic Localization Mod for The Last of Us Part I (PC)!
Created by Mohamed Moslem Allouch.

FEATURES:
- Full Arabic Narrative & Dialogue Subtitles: Professionally reshaped and RTL-aligned with pristine, seamless cursive letter connections (no broken joints or gaps).
- Ambient & Combat Subtitles: Systemic barks, enemy shouts, and world dialogue in Arabic.
- Document / Note Reader: In-game letters, artifacts, and diary entries fully translated to Arabic (displayed cleanly when pressing the 'Read' button).
- English Speaker Names Preserved: Speaker names remain on the far right (e.g. [Dialogue] :SARAH).
- Pristine UI & Menus: Original English user interface, options, HUD, and Latin fonts are 100% untouched to prevent UI text clipping and memory pool overflows.
- Persistent Arabic Subtitles: Both English (US) and French slots are localized into Arabic! No need to manually switch languages every time you restart—the game boots directly into Arabic subtitles automatically!
- 100% Safe: Automatically creates full backups of your game files before applying any changes. Easily uninstalled at any time.

HOW TO INSTALL:
1. Extract the contents of this archive (or copy "TLOU_Arabic_Mod_Installer.exe") into your main game directory (where 'tlou-i.exe' is located).
   * Note: The installer can automatically detect your game directory, or open a Windows folder selection window if needed.
2. Double-click "TLOU_Arabic_Mod_Installer.exe".
3. Choose Option [1] to Install. The installer will automatically:
   - Create backups of your original files (.orig_bak).
   - Patch the game executable for RTL layout and seamless Arabic rendering.
   - Inject the Arabic fonts and dialogue into core.psarc (~30 seconds).
4. Launch the game! The subtitles and notes are already active in Arabic!

HOW TO UNINSTALL:
Run "TLOU_Arabic_Mod_Installer.exe" again and select Option [2] to restore your original game files.
